Git birthday for 2024

D Dragon · 2025年01月18日 · 1211 字 · 4 分钟阅读

又是一年，掰指头数数现在已经是第四年的结尾了，这是我往个人日历里面插入的第一个纪念日，用来纪念我入行的那天。

Git birthday，笑死，现在在程序猿这条路上渐行渐远了。

建立博客的初衷是想分享技术，就像大多数个人blog一样。先辈们也曾尝试在大大小小的平台上面建立一个技术“乌托邦”，但碍于不可抗力，他们不得不散开来，在虚拟世界搭建起了一个又一个庇护所。在这个虚拟世界中，我算是原住民，也是个旅行者，每天都在里面走走停停，通过一些模糊的指引，走到某些奇怪的建筑旁边，这些建筑有的在营业中，有的在装修，有的已经变成古迹供人朝拜，也有的只剩下断臂残垣。我曾经看过一个二十八岁博士波澜壮阔的一生，人们在他的楼下驻足，悼念。也经常路过涵盖从汇编到AIGC，文档格式到面试宝典的宝藏小屋。逛着逛着我就想，要不我也定一个赛博锚点吧，把一切我觉得珍贵的记忆都放在这，等待后人翻阅。

我的小楼还在搭建，但不知怎么就变成了类似朋友圈日记本一样碎碎念的地方。技术力技术力，程序员最重要的技术力啊，我不知道该在文章的哪段插入。关于我这半吊子的技术力，关于后端吗？还是前端，又或者项目思路，框架运用，服务器搭建…… 什么都会一点，却什么都半吊子。我总跟别人说：完成比完美更重要，但我貌似并没有很深入的去研究过某种技术，22年我的第一个项目完成时，我是打算写一篇《基于宝塔的阿里云远程Windows服务器操作指南》，后面因为插本等原因也不了了之了。没想到的是，算上所谓“代码开窍”后的工作时间，2022年的那个暑假，居然是我离技术核心最近的时刻，我该在那时写下很多技术上的Blog，关于Vue，关于跨域(最折磨的一集)，关于服务器操作配置，关于boot注释…… 。

我是吃开源社区的百家饭长大的，但我却并没有很好的回馈这个社区。

前几天帮Jimmy改前端代码写到凌晨三点，带着耳机，听着爵士，吹着牛逼，骂着Edge，好不快活，说说笑笑间他突然冷不丁的问我一句：“龙哥，你以前真的通宵写代码啊？”，我叉掉F12，“跟你开玩笑咩，我他妈差不多通了三年宵”。

代码，编程，数据结构，我曾经的热爱还能维持多久，要说成就吧，也不是没有，比赛，工作，社团，再到今年的答辩，我近几年的自我都由代码带来，但我总感觉不够，我变得越来越功利，总想着用更少的代码和时间去换取更高的利润，这算贪心吗？一方面讲，这是体力劳动向脑力劳动的转变，另一方面，我可能再也回不去当初花几小时改一个bug能高兴一晚上的心态了，这算进步吗？现在的一些作业或者模型训练，我习惯于去研究框架和逻辑，编码什么的扔给AI，我到底还算一个合格的程序员吗？单从自我评价来讲，我觉得我已经失职了。

23年六月的经验分享会上，我曾经说过：专注能让你走得更高，热爱能让你走得更远。

要说不爱吧，凌晨三点的Debug让我好像回到了活动室，回到当年那个能盯着控制台打印数据发笑的时候，要说爱吧，现在也很少有时间精力去写一些循环，实现一些方法，研究新的技术，甚至码一篇博客。时间，又是时间，总是时间，你所有未成之事都怪给了时间，真有意思。

我喜欢编码，我的梦想是做一个类似JARVIS的人工智能，幻想着我哪天疲惫地推开家门，充满科幻感的机械男嗓音道：Welcome home ，Sir。现在也打算往人工智能方向发展，毕业设计也是在研究分析卷积神经网络。

好了，生日快乐！

保持热爱，保持专注，你会赢得更多

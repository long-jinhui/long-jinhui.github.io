Git Birthday

D Dragon · 2023年11月23日 · 468 字 · 2 分钟阅读

生日快乐！

​ 今天是git生日 不知不觉过了三年了 现在我也爬到了本科的阶段 实习之后 编辑代码的时间明显下降了很多 开始变成如何构思了 加上转入这个大数据专业 就越来越理解：不管python java都只是一门编程语言。

​ 语言用什么不重要 软件就用java 数据多就用python 考试就学c，语言只是工具 代码不重要 要根据业务去选择对应的语言

​ 想起在专科的时候跟千羽师兄讨论过这个问题 那时还傻乎乎的问他：那我只精通java行不行？ 以现在的角度去看当初的自己无疑是十分幼稚的。

​ 不过现在代码得告一段落了 那天上课我看到21年的代码提交记录 是一整年的全勤 然后是接下来只有零星记录的二二年 和基本毫无代码提交的二三年

​ 为了晋升 我需要一个本科学历 而因为本科学历的泛滥和廉价 我要拿下研究生

​ 回望两次大考 都因为奇奇怪怪的原因失利

​ 20年高考的本科投档线是410 最终录取线是420 当时我独自一人在房间里背靠座椅心如死灰 至今仍会被噩梦惊醒。

​ 经历了两次的失败后 我在想如果再有一次这样的学历考试 我一定要赢下所有 25考研迫在眉睫 我必须考虑这是不是我此生仅有的机会 我相信三年能达到这样的高度 自己功不可没

拿下最高学历 吾辈义不容辞
